# Reuse audit: V1/V2 Blob Analyzer → V3 Object Counter

Source: the archived project in `old/` (read-only, never imported). Verdicts:

- **Reused:** copied with cosmetic changes.
- **Adapted:** ported with real changes.
- **Concept only:** the idea carries over, the code does not.
- **Dropped.**

"Ported to" names the file in the new tree.

## Ported in Phase 0

| Old module                                                | Verdict                  | Ported to                          | Reasoning                                                                                                                                                                                                                                                                                       |
| --------------------------------------------------------- | ------------------------ | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tracking/AssignmentSolver.ts`                            | Reused                   | `src/tracking/AssignmentSolver.ts` | Hungarian assignment is exactly what ByteTrack-style association needs; only blob wording removed. It now has a brute-force-checked test.                                                                                                                                                       |
| `utils/timing.ts` (`formatTimecode`, `formatFileSize`)    | Reused                   | `src/utils/format.ts`              | Generic formatting for the timeline and file-size errors. Frame/second helpers dropped (frame numbers will come from timestamps).                                                                                                                                                               |

| `styles/*.css`                                            | Adapted                  | `src/styles/main.css`              | Kept the color tokens and stage/upload/panel styles; rewritten compactly, with a single-column layout under 860 px.                                                                                                                                                                             |
| `app/App.ts`                                              | Concept only             | `src/app/App.ts`                   | "App is the only module that knows everything" carries over; the wiring is new.                                                                                                                                                                                                                 |

## Concept carried forward, code written in a later phase

| Old module                                                                   | Verdict                  | Reasoning                                                                                                                                                                                                                                                        |
| ---------------------------------------------------------------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tracking/TrackManager.ts`, `Track.ts`, `TrackLifecycle.ts`, `TrackTypes.ts` | Concept only (Phase 4)   | Keeps the store-plus-lifecycle shape (tentative → active → lost → removed, listeners). The fields, merge/reidentification logic and normalized-point history are blob-specific, so ByteTrack-style tracks with `classId`/`label`/`confidence` are written fresh. |
| `workers/AnalysisWorker.ts`                                                  | Concept only (Phase 1/2) | Keeps "downscale a transferred frame on an OffscreenCanvas in the worker, close the frame, reply with transferables". The body is OpenCV-bound and gets replaced by letterbox + ONNX.                                                                            |
| `tests/settingsPanel.test.ts`, `tests/settings.test.ts`                      | Concept only             | The happy-dom panel test and the store test patterns were reused for the new tests.                                                                                                                                                                              |
| `scripts/eval/ffmpegFrames.ts`                                               | Deferred                 | The ffmpeg-based headless frame decoding may help Phase 1 (test stills) and Phase 4 (clip counts). It will be re-evaluated then, not ported speculatively.                                                                                                       |
